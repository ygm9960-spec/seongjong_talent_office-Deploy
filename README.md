- 특수심사의 조건을 만족하고 정답을 맞히면 +110~140점 보너스를 받습니다.
- 조건을 놓치면 속도 보너스가 사라지고 콤보 보너스가 절반으로 줄어듭니다.

- 결과 화면에서 특수심사 성공 수와 돌발이벤트 경험 수를 확인할 수 있습니다.

## v10.4 - Google Sheets 공용 명예의 전당
- 명예의 전당 TOP 20 표시
- 메인 화면 / 결과 화면 새로고침 버튼 추가
- Google Apps Script를 통해 일반모드 결과 자동 저장
- 동일한 `학번 + 이름`은 최고 점수 1개만 순위에 표시
- 순위 기준: 점수 → 정확도 → 최고 콤보 → 남은 시간
- 인터넷 또는 API 연결 실패 시 기기 내 기록을 임시 표시
- Google Sheet 자체는 공개할 필요 없음

### 연결에 필요한 마지막 설정
1. `backend/Code.gs`를 Google Sheet의 Apps Script에 붙여 넣습니다.
2. Apps Script에서 `setup()`을 한 번 실행합니다.
3. 웹 앱으로 배포하고 `/exec` URL을 복사합니다.
4. `config.js`의 `GOOGLE_SHEETS_WEB_APP_URL`에 URL을 붙여 넣습니다.
5. 웹앱을 배포한 뒤 명예의 전당 `새로고침`을 눌러 연결을 확인합니다.

자세한 내용은 `backend/구글시트_연결방법.txt`를 참고하세요.

## v10.6 BGM 통합

사용자가 제작한 7개의 MP3 테마를 `assets/audio/bgm/`에 포함했습니다.

- `01_main_theme.mp3` — 메인 화면
- `02_prologue_theme.mp3` — 프롤로그
- `03_review_theme.mp3` — 튜토리얼·일반 심사
- `04_special_review_theme.mp3` — 특수심사
- `05_sudden_event_theme.mp3` — 돌발이벤트
- `06_final_review_theme.mp3` — 20번째 최종 중요 심사
- `07_result_theme.mp3` — 결과 화면

음악은 상황 전환 시 짧게 페이드 전환하며 반복 재생됩니다. 모바일 자동재생 제한 때문에 첫 터치/키 입력 이후 음악이 시작됩니다. 설정의 `음악·효과음` 토글은 기존 Web Audio 효과음과 BGM을 함께 켜고 끕니다. 페이지가 백그라운드로 가면 BGM은 잠시 멈추고, 복귀하면 현재 화면에 맞는 테마를 이어서 재생합니다.
