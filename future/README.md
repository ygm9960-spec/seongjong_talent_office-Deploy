# 향후 이미지 슬롯

현재 v6는 아래 슬롯을 CSS 자리표시자로만 사용합니다. 나중에 이미지를 제작하면 이 폴더에 넣고 `app.js`의 `OPTIONAL_ASSET_SLOTS` 경로만 채우면 됩니다.

- prologue_01.webp ~ prologue_05.webp : 프롤로그 5컷
- special_conflict.webp : 엇갈린 추천
- special_missing.webp : 가계 기록 누락
- special_urgent.webp : 심사 재촉
- special_seal.webp : 수상한 인장
- special_birthplace.webp : 엇갈린 출신지
- special_propertyjump.webp : 갑자기 늘어난 토지
- special_joint.webp : 공동 천거
- special_torn.webp : 찢어진 상소문
- combo_03.webp / combo_05.webp / combo_08.webp / combo_10.webp : 콤보 연출용 이미지
- final_directive.webp : 마지막 중요 심사 연출
- game_end.webp : 심사 종료 연출

현재 파일이 없어도 게임은 정상 동작합니다.
